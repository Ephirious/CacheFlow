# Core Validation Module

## Назначение

`core-validation` — общий модуль валидации, используемый другими feature-модулями.

## Подтвержденные сведения

На уровне Gradle-конфигурации модуль:

- является shared-модулем;
- зависит от `shared:utils:pure`.

## Архитектурная роль

Модуль используется как общее место для правил проверки входных данных и бизнес-ограничений, которые переиспользуются между feature-модулями.

## Зависимости

```text
core-validation
    ↓
utils:pure
```

## Использование

Подтвержденная зависимость на модуль присутствует в `auth:domain`.

Это позволяет использовать единые validation rules в сценариях регистрации, авторизации и других пользовательских действиях.

## Примечание

Данный README описывает архитектурную роль модуля. Список конкретных validator-классов должен поддерживаться по мере развития модуля и документироваться только для реально существующих реализаций.
