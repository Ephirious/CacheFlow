# Модуль core-validation

Изменено: 02.06.2026

`core-validation` предназначен для общих правил проверки данных, которые используются в разных feature-модулях.

На текущий момент через код удалось подтвердить только архитектурную роль модуля и его зависимости. Конкретные валидаторы пока специально не перечисляются, чтобы документация не расходилась с кодом.

## Зависимости

```text
core-validation
  ->
utils:pure
```

Также зависимость на этот модуль используется в `auth:domain`.

## Для чего он нужен

Идея модуля простая: правила проверки не должны дублироваться между авторизацией, редакторами и другими частями приложения.

Если появляется логика валидации, которая нужна сразу в нескольких местах, её стоит размещать здесь.
