# Синхронизация

Изменено: 02.06.2026

Серверная синхронизация реализована в `SyncService`.

Клиент отправляет список операций и дату последней синхронизации. Сервер применяет изменения и возвращает актуальное состояние.

## Поддерживаемые операции

Для каждой сущности поддерживаются:

- CREATE
- UPDATE
- DELETE

Сейчас синхронизация работает со следующими таблицами:

- ACCOUNTS
- OPERATIONS
- CATEGORIES
- TRANSFER

## Как проходит синхронизация

```text
SyncRequest
  -> group operations
  -> apply create/update/delete
  -> save sync history
  -> collect changes
  -> SyncResponse
```

Во время обработки сервер проверяет историю операций и отбрасывает устаревшие обновления.

## Ответ сервера

`SyncResponse` содержит:

- `accepted_ids`
- `delete_operations`
- `update_state`
- `last_sync_date`

Клиент использует эти данные для обновления локальной базы.

## Особенность счетов

После изменения операций сервер дополнительно пересчитывает затронутые счета и добавляет обновлённые данные в ответ. За счёт этого клиент получает актуальный баланс без отдельного запроса.
