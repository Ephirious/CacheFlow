# Архитектура backend

Изменено: 02.06.2026

Backend построен вокруг FastAPI, SQLAlchemy и Alembic. В коде используется разделение на роуты, сервисы, репозитории и модели базы данных.

## Основной поток

```text
HTTP request
  -> FastAPI router
  -> dependency
  -> service
  -> UnitOfWork
  -> repository
  -> SQLAlchemy model
  -> PostgreSQL
```

Роуты не должны содержать бизнес-логику. Их задача - принять запрос, получить зависимости и вызвать нужный сервис.

## Сервисы

Сервисы находятся в `src/services`.

Сейчас основные сервисы:

- `AuthService`
- `SyncService`

Сервис работает через `UnitOfWork`, а не напрямую с SQLAlchemy session. Это позволяет держать транзакцию в одном месте и явно делать commit или rollback.

## Репозитории

Репозитории находятся в `src/repositories`.

Типовые операции вынесены в `GenericRepository`. Если новой сущности достаточно стандартных CRUD-операций, не нужно писать их вручную заново.

## Схемы

`src/schemas` содержит Pydantic-модели для входных и выходных данных.

Сервисы возвращают `Result`, чтобы роуты могли одинаково обрабатывать успешный ответ и ошибку.

## Миграции

Миграции лежат в `src/migrations` и управляются Alembic.

Если меняется модель базы данных, нужно создать новую миграцию и проверить её применение локально.
