# Безопасность

Изменено: 02.06.2026

Основная логика безопасности находится в `src/core/security.py`.

## Пароли

Для паролей используется bcrypt.

Основные методы:

- `Password.encrypt(...)`
- `Password.verify(...)`

В коде также есть поддержка SHA-256, но основной сценарий работы использует bcrypt.

## Одноразовые коды

Для подтверждения регистрации используются OTP-коды.

Генерация выполняется через:

```python
Password.generate_otp()
```

По умолчанию создаётся шестизначный код.

## JWT

Токены создаются через:

```python
Token.create_token(user_id)
```

Создаются два токена:

- access token
- refresh token

Оба подписываются алгоритмом HS256.

## OAuth2

Для получения токена пользователя используется:

```python
OAuth2PasswordBearer
```

Точка входа для логина:

```text
/auth/login
```

## Маскирование email

Для отображения адреса пользователю используется `Email.mask(...)`.

Например:

```text
user@example.com
->
us***r@example.com
```
