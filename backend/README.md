## How-to для чайников

### 1. How-to "Добавить новую модель и описать взаимодействие с ней"

1. Создать файл ``cool_model.py`` в ``src/model`` и описать SQLAlchemy модель. <br> **Ахтунг!** Если модель не будет наследоваться от [Base](src/models/base_class.py), руки контрибьютера имеют риск перестать быть единым целым с его телом
2. Добавить созданную модель в ``src/models/__init__.py``
3. Создать файл ``cool_model.py`` в ``src/repositories``, описать репозиторий. <br>
    **Ахтунг!** Если репозиторий не будет наследоваться от [GenericRepository](src/repositories/base.py), исходный код будет удален с компьютера контрибьютера, а доступ к проекту закрыт навсегда
4. Создать файл ``cool_service.py`` в ``src/services``, описать сервис
   <br> **Ахтунг 1!** Если в сервисе будет ручная работа с сессией(а не через [UOW](src/repositories/uow.py)), компьютер контрибьютера имеет риск взорваться
    <br> **Ахтунг 2!** Если методы сервиса не будут возвращать [Result](src/schemas/result.py), вероятность падения кирпича на голову контрибьютера увеличивается на 100%
